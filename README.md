# 📂 Featured Projects

## 🏥 Medical Appointment No-Shows

Analyzed **110,521 medical appointments** to investigate how SMS reminders, patient age, and scheduling lead time relate to missed appointments.

The project included data cleaning, feature creation, exploratory analysis, and visualization to identify patterns associated with appointment attendance.

### Key findings
- Patients who received SMS reminders had a higher observed no-show rate in this dataset.
- Patients who missed appointments were younger on average than those who attended.
- Scheduling lead time was explored as another factor related to attendance behavior.

### Skills demonstrated
Python • pandas • NumPy • Matplotlib • Data Cleaning • EDA • Data Visualization

## 🚲 Ford GoBike Data Visualization

Explored **183,412 Ford GoBike trips** from February 2019 to understand trip behavior and differences between Customers and Subscribers.

The project included exploratory and explanatory analysis using Python, pandas, Matplotlib, and Seaborn.

### Key findings
- Most bike trips were relatively short.
- Subscribers accounted for the majority of trips.
- Customers generally took longer and more variable trips than Subscribers.

### Skills demonstrated
Python • pandas • Matplotlib • Seaborn • EDA • Data Visualization • Analytical Storytelling
