### 🚲 Ford GoBike Data Visualization

Explored **183,412 Ford GoBike trips** from February 2019 to understand trip behavior and differences between Customers and Subscribers.

Performed exploratory and explanatory analysis using Python, pandas, Matplotlib, and Seaborn, then communicated the main findings through focused visualizations.

Key findings included that most trips were relatively short, Subscribers made the majority of trips, and Customers generally took longer and more variable trips.

**Skills:** Python • pandas • Matplotlib • Seaborn • EDA • Data Visualization • Analytical Storytelling

[View Project](https://github.com/Labbouyat/ford-gobike-data-visualization)
